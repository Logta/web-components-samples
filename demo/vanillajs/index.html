Web Components in Vanilla JS Demo

このデモでは、純粋なJavaScript環境で3つの異なるWeb Componentsを使用しています。

1. Vanilla JS Counter

純粋なJavaScriptで作成されたWeb Component

2. React Counter (as Web Component)

Reactで作成されたコンポーネントをWeb Componentとしてラップ

3. Lit Counter

Litフレームワークで作成されたWeb Component

4. 動的に追加

JavaScriptでWeb Componentを動的に作成

使い方

各カウンターの + / - ボタンをクリックして、カウンターを操作できます。

「カウンターを追加」ボタンをクリックすると、JavaScriptで動的にWeb Componentが追加されます。

フレームワークを使わなくても、標準のWeb Components APIだけでインタラクティブなUIを構築できます。
