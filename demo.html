🎯 Web Components Samples

Vanilla JS、Lit、Reactで構築したWeb Componentsの比較デモ

Vanilla JS Vanilla JavaScript

純粋なJavaScriptとCustom Elements APIを使用して構築。 フレームワークなしで軽量、ブラウザネイティブのAPIのみを使用。

Lit Lit Framework

Litフレームワークを使用して構築。 宣言的なテンプレート、リアクティブプロパティ、効率的な再レンダリングを提供。

React React

ReactコンポーネントをWeb Componentとしてラップ。 React開発者に馴染みのある方法でWeb Componentsを作成可能。

📦 技術スタック

  • ビルドツール: Vite
  • パッケージマネージャー: pnpm
  • モノレポ: pnpm workspace
  • Web Components API: Custom Elements, Shadow DOM

🚀 使い方

  • 開発モード: pnpm dev
  • ビルド: pnpm build
  • 個別パッケージ: cd packages/vanilla && pnpm dev
